# HACKED_404 🎓
## SmartCampus — AI-Powered Attendance & Student Productivity Platform

> Attend smarter. Learn faster. Connect better.

## 🚀 Features
- 🎥 Classroom camera auto face recognition
- 📍 GPS geofencing for physical presence verification  
- 🧠 Liveness detection (blocks photo spoofing)
- 🤖 ML-based dynamic leave calculator
- 📄 PDF timetable parser & curriculum tracker
- 👥 Free slot matcher for student collaboration
- ⚠️ Early attendance warning system
- 🎯 Activity & event management
